# 🎯 SPb Lead Bot — Поиск клиентов на разработку сайтов в Санкт-Петербурге

Приватный Telegram-бот для поиска, скоринга и квалификации заведений Санкт-Петербурга, которым потенциально нужна разработка или починка сайта.

## 🚀 Возможности
- Бесплатный парсинг районов СПб через OpenStreetMap (Overpass API) + поддержка 2GIS API 3.0.
- Импорт CSV-выгрузок из десктопных парсеров Яндекс Карт и 2ГИС.
- Автоматический HTTP-чекер сайтов:
  - `dead_site` — в карточке указан домен, но сайт не работает (404/502, истек домен, упал SSL).
  - `social_only` — вместо сайта ссылка на группу ВК, Telegram, Taplink или YClients.
  - `no_site` — сайт отсутствует, но есть телефон или соцсети для связи.
- Скоринг (0–100 баллов) с учетом маржинальности ниши и полноты контактов.
- Мини-CRM внутри Telegram (`Новые`, `В работе`, `Нецелевые`) + генерация шаблона первого сообщения для клиента.

## 🛠 Быстрый старт

1. Создайте виртуальное окружение и установите зависимости:

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и ваш `ADMIN_TG_ID`.
3. Запустите бота:

    python main.py

4. Тесты (сеть не используется):

    pytest

### Запуск в Docker

`docker-compose.yml` монтирует файл `./leads.db`. Создайте его до первого запуска, иначе Docker создаст на его месте каталог и SQLite не сможет открыть базу:

    touch leads.db
    docker compose up -d --build

## 📥 Формат CSV для ручного импорта
Бот поддерживает загрузку `.csv` файлов (разделитель `,` или `;`, кодировка `UTF-8` или `Windows-1251`). Распознаются колонки:
- `name` / `Название` / `Имя`
- `category` / `Рубрика` / `Категория`
- `district` / `Район`
- `address` / `Адрес`
- `phone` / `Телефон` / `Телефоны`
- `website` / `Сайт` / `Web`
- `socials` / `ВК` / `VK` / `Telegram`
